# Instrucciones
El desafío FizzBuzz es una de las tareas de entrevista de programación más comunes del mundo. El reto consiste en escribir un programa que genere una lista de números, reemplazando cada tercer número por "Fizz" y cada quinto número por "Buzz".

**Hoy construirás y desarrollarás este desafío, y aprenderás a utilizar bucles `for` en el proceso.**

Para cada tarea, copia el código de la tarea anterior y amplíalo en la siguiente.


## Tareas

1. ¿Puedes crear un programa en JavaScript que muestre todos los números del 1 al 105? 
* No superarás esta tarea si tu programa se detiene antes de llegar a los 105 números. **¡Las computadoras son muy literales!**

2. Copia el código de `task1.js` en `task2.js`. ¿Puedes ahora reemplazar cada tercer número por "Fizz"? 
* ¡Asegúrate de que tu código muestre únicamente "Fizz" para esos números!

3. ¿Puedes también reemplazar cada quinto número por "Buzz" y aquellos que cumplan ambas condiciones por "FizzBuzz"? 
* Asegúrate de que el resultado muestre "FizzBuzz" en una sola línea, y no en dos líneas separadas ni en el orden incorrecto.

4. ¿Puedes continuar el patrón reemplazando también cada séptimo número por "Woof", además de cumplir las otras condiciones? 
* El orden lógico de salida, en caso de que un número cumpla todas las condiciones, es: "Fizz", luego "Buzz" y finalmente "Woof".
