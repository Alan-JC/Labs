# Instructions  

1. Convierte "COME TO BUERGER TOWN!" en una alerta interactiva (al hacer clic) que muestre el mensaje "ITS BURGERTIME".
   - Asegúrate de utilizar el atributo `OnClick` para esta parte.
2. Cuando alguien haga clic en "BURGER TOWN!", se debe mostrar el mensaje "Someone click on BURGER TOWN!" en la consola (`console.log`).
3. Añade una imagen de una hamburguesa debajo del título "A picture of a BURGER!".
   - Consejo: Puedes usar Google para ayudarte con esta sección.
4. Cada vez que alguien haga clic en la palabra "RICE!!", el texto del título "A Picture of a BURGER" debe cambiar a color rojo.
