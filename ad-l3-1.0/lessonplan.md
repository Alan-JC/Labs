# Instrucciones:

## Sección HTML
- Inserta imágenes para todas las letras del abecedario.
- Corrige cualquier error visible.

## Sección CSS

- Vincula `style.css` al HTML.
- Establece el color de fondo en gris.
- Establece el color de los elementos `h3` en verde.
- Crea una clase para aplicar el color azul a tres elementos `h3`.
- Establece el color de un elemento `h3` específico en rojo.

## Sección JavaScript

- Vincula `script.js` al HTML.
- Crea una función que aplique 3 colores aleatorios:
  - Verde, azul y rojo.
- Cuando alguien haga clic en cualquier etiqueta `h5`, haz que cambien entre esos 3 colores aleatorios de forma repetible:
  - Verde, azul y rojo.

# Comienza esta actividad...
> ¡Realizando una reunión Scrum!
>
> Tu equipo debe crear un tablero de proyecto y luego generar tarjetas y tareas (*issues*) para cada actividad. Este proceso es repetitivo y sirve como práctica. Inicia tu primer *sprint* priorizando las tareas más sencillas (como las letras, por ejemplo) a las que todos puedan acceder; una vez que cada persona termine su tarea, cierra la tarjeta y la tarea correspondiente, y pasa a la siguiente.
>
> Practica el uso de ramas (*branching*) en tu repositorio creando una nueva rama para cada tarea en la que trabajes. Por ejemplo, si se te asignan personalmente las letras C a F, crea una rama llamada "letterC-F". Una vez que termines esas letras y hayas finalizado con la rama actual, asegúrate de crear una nueva rama para las siguientes letras. Por ejemplo, si tu siguiente tarea corresponde a las letras G-I, tu rama debería llamarse "letterG-I".

## Comandos útiles para crear ramas y cambiar a ellas...
    - `git branch` (muestra las ramas locales actuales)
    - `git branch branchName` (crea una nueva rama)
    - `git checkout branchName` (cambia a la rama indicada)
    - `git checkout -b branchName` (crea una nueva rama y cambia a ella)

## Cómo subir (push) una rama... 
    - `git status`
    - `git add .`
    - `git commit -m 'messages'`
    - `git status`
    - `git pull origin main`
    - `git push origin branchName`
