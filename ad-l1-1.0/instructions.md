# Plan de la lección
> Sigue las instrucciones para vincular `style.css` y `script.js`, y luego añade algunas funcionalidades al sitio web.

## Instrucciones:

### Sección HTML
>- **Añade** un encabezado que diga "Hello world!".
>- **Inserta** una imagen desde la carpeta "Picture".
>- **Añade** un atributo `id` con el valor "red".
>- **Añade** cuatro encabezados más que digan "Hello world".
>- **Añade** dos atributos `class` con el valor "blue".

### Sección CSS
>- **Vincula** el CSS al HTML.
>- **Haz** que todos los elementos `<h1>` sean de color verde.
>- **Define** la clase "blue" y aplica el color azul al texto.
>- **Define** un ID con el valor "red" y aplica el color rojo al texto.

### JavaScript
>- **Vincula** el JavaScript al HTML.
>- **Modifica** el primer "Hello World!" para que diga "GoodBye" usando JS.
>- **Cambia** el color de fuente de un encabezado a naranja usando JS.
>- **Añade** un encabezado interactivo (en el que se pueda hacer clic) que cambie el color de fuente a marrón usando JS.

#### Consejo:
> Familiarízate con el atributo `id`, ya que se utilizará ampliamente en esta actividad.
